Go  - Product Catalog service  # build go binaries
===============================
 - apt install golang-go
 - export PRODUCT_CATALOG_PORT=8088
 - go build -o product-catalog   # create the build where destination -o #service name
 - ./product-catalog     # to run builded binaries 
 
Write Docker file:
-----------------
  -/product-catalog
  - rm rf Docker file
  - Write Dockerfile
  - ##Refer Dockerfile ##
  - docker build -t sudharsan/product-catalog:v1 .
  - sudo docker run sudharsan/product-catalog:v1

Java: Ad service 
=================

Java build with Maven or gradle 
 - gradle - gradlew  #dependency file 
 
 - sudo apt install openjdk-21-jre-headless
 - ./gradlew installDist
 - chmod +x gradlew  #if not have permission 
 - refer project repo  -java #https://github.com/iam-veeramalla/ultimate-devops-project-demo/blob/main/src/ad/README.md
 
  - export AD_PORT=8080
  - export FEATURE_FLAG_GRPC_SERVICE_ADDR=featureflagservice:50053
  - ./build/install/opentelemetry-demo-ad/bin/Ad   #started run program from Ad executable
